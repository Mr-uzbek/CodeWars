# Codewars Solutions 🥷

A collection of my daily Codewars challenges solved in JavaScript (and soon TypeScript). This repository tracks my progress in mastering algorithms, data structures, and problem-solving skills.

## 🎯 Goals
- Solve at least one algorithm challenge daily.
- Improve problem-solving speed and code efficiency.
- Refactor old solutions as I learn new techniques.

## 📂 Repository Structure
Solutions are organized by their difficulty level (kyu):
- `8-kyu/` - Fundamentals
- `7-kyu/` - Beginner
- `6-kyu/` - Novice (Coming soon)

## 💻 Tech Stack
- JavaScript (ES6+)
- TypeScript
- Node.js

## 📹 Explanations & Tutorials
For some of the interesting challenges, I record 15-minute video breakdowns explaining my logic and the optimal solution. You can find these tutorials on my platform: [coding.uz](https://coding.uz).

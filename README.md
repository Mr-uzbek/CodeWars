# 🥋 Codewars Solutions

This repository contains my collection of solutions for programming challenges (katas) from the [Codewars](https://www.codewars.com/) platform. The challenges are organized by difficulty level, ranging from 8-kyu (easiest) to 1-kyu (hardest).

![Codewars Badge](https://www.codewars.com/users/Mr-uzbek/badges/large)

## 📁 Directory Structure

The folders are structured based on the Codewars ranking system, with each level representing a specific difficulty of logic and algorithms:

*   `1-kyu (Expert)` - Expert level problems requiring unconventional approaches, systems programming, and highly complex logic.
*   `2-kyu (Proficient, Expert)` - Extremely difficult challenges based on advanced Computer Science theories.
*   `3-kyu (Competent)` - Large and complex systems, difficult architectural design problems.
*   `4-kyu (Advanced, Competent)` - Complex problems and advanced Object-Oriented Programming (OOP) concepts.
*   `5-kyu (Novice)` - Serious algorithmic challenges where code optimization and performance matter.
*   `6-kyu (Intermediate, Novice)` - More complex logic requiring multi-step algorithms.
*   `7-kyu (Beginner)` - Basic data structures and intermediate logical problems.
*   `8-kyu (Fundamentals)` - The fundamental rules of programming languages and basic syntax practice.

## 💻 Technologies & Languages

The solutions in this repository are primarily written using modern web technologies:
*   **JavaScript (Node.js)**
*   **TypeScript**

## 🚀 How to Use

Inside each kyu folder, there are separate files named after the specific challenge. Each file typically contains:
1. A brief description or requirement of the challenge.
2. My personal solution (code).
3. (Optional) Alternative, refactored, or highly optimized solutions.

Beginner developers are welcome to review these codes, compare them with their own solutions, and explore new problem-solving approaches.
